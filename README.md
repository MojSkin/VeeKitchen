## ✨ وی‌کیچن چیست؟

وی‌کیچن، دستیار کامل رستوران شماست؛ از میزی که مشتری با اسکن QR سفارش می‌دهد تا نمایشگری که «شماره ۳ میز ۵» را صدا می‌زند — همه‌چیز بلادرنگ و روی موبایل هم به‌اندازهٔ دسکتاپ خوش‌دست.

- 📱 **منوی دیجیتال با QR** — مشتری اسکن می‌کند، میز را رزرو می‌کند و سفارش می‌دهد؛ بدون اپلیکیشن
- 💳 **صندوق هوشمند** — سفارش‌ها آنی به صندوق می‌رسند، با یک کلیک پرداخت و شماره‌گذاری می‌شوند
- 🍕 **صف آشپزخانه (KDS)** — سفارش‌های تازه، بلادرنگ روی نمایشگر آشپز
- 🔊 **اعلام صوتی فارسی** — «آماده تحویل» با صدای فارسی روی نمایشگر کنار صندوق
- 🏬 **چندشعبه‌ای از روز اول** — گزارش و مدیریت، به تفکیک شعبه یا تجمیعی
- 🌙 **روشن/تاریک خودکار** — با رابط شیشه‌ای و فارسیِ کاملاً راست‌به‌چپ

## 🚀 راه‌اندازی سریع

پیش‌نیازها: PHP 8.3+ · Composer · Node.js 20+ · MySQL (فقط برای پروداکشن)

```bash
git clone https://github.com/MojSkin/VeeKitchen.git
cd VeeKitchen

composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed    # ← سیدر: شعبه، منوی نمونه و کاربران تست

npm install
composer run dev              # ← هر چهار سرویس هم‌زمان بالا می‌آیند
```

سپس آدرس [`http://localhost:8020`](http://localhost:8020) را باز کنید.

## 🌿 مدل شاخه‌ها (Git Flow)

```
main ←── testing ←── development ←── feature/*
         (تست سبز)        (کار روزانه)
```

- هیچ تغییری مستقیم روی `main` پوش نمی‌شود
- هر تسک روی برنچ `feature/*` جدا از `development` ساخته می‌شود
- نسخه‌بندی بر اساس [`CHANGELOG.md`](CHANGELOG.md) و با تگ روی `main`
- قوانین کامل: [`.ai/rules/git.md`](.ai/rules/git.md)
